## 插件介绍

QQ消息伪装插件（astrbot_plugin_msg_spoof）是一款为 AstrBot 开发的趣味插件，可以伪装成任意QQ用户发送消息，并以**聊天记录转发（合并转发）**的形式呈现。插件支持自动获取QQ用户真实昵称，支持文本、图片、表情等多种消息类型。

## 功能特点

- **快捷伪装**：一条命令快速生成多用户伪装聊天记录
- **详细伪装**：多轮对话式添加消息，支持随时切换伪装用户
- **自动获取昵称**：通过API自动获取QQ用户真实昵称
- **多类型消息**：支持文本、图片、表情等消息类型
- **黑白名单管理**：支持群黑名单/白名单模式，灵活控制使用范围
- **超时自动重置**：详细伪装模式30秒无操作自动重置
- **转发消息呈现**：所有结果以QQ合并转发聊天记录形式发送

## 安装方法

### 方法一：插件市场安装
1. 打开 AstrBot WebUI 管理面板
2. 进入「插件市场」
3. 搜索 `QQ消息伪装` 或 `msg_spoof`
4. 点击安装即可

### 方法二：手动安装
1. 下载本插件的 ZIP 压缩包
2. 将压缩包解压到 AstrBot 的 `data/plugins/` 目录下
3. 确保目录结构为 `data/plugins/astrbot_plugin_msg_spoof/`
4. 在 AstrBot WebUI 插件管理中点击「重载插件」

### 方法三：Git 安装
```bash
cd AstrBot/data/plugins
git clone https://github.com/AethenNet/astrbot_plugin_msg_spoof.git
```
然后在 WebUI 中重载插件。

## 使用方法

### 1⃣ 快捷伪装

**命令：** `/伪装` （别名：`伪装消息`）

**格式：**
```
/伪装 <用户1QQ号> <文本|图片|表情> <用户2QQ号> <文本|图片|表情> ...
```

**说明：**
- 第一个参数必须是QQ号
- 后续参数中，遇到纯数字（5-11位）自动识别为新的伪装QQ号
- 其余内容作为当前用户的消息，可以是文本、图片、表情
- 一个用户可以发送多条消息
- 支持无限衔接更多用户

**示例：**
```
/伪装 12345678 你好 123456789 你好！
```
```
/伪装 123456 文本 图片 文本 1234567 图片 文本
```

### 2⃣ 详细伪装

**命令：** `/伪装x` （别名：`伪装x消息`、`伪装消息x`）

**说明：**
- 启用多轮对话式伪装，适合复杂场景
- 每条指令最多只能一个人使用（按使用者QQ号隔离）
- 30秒无回复自动超时重置
- 发送 `结束`、`完成` 或 `生成` 来结束并生成转发消息

**交互流程：**

1. 启动指令后，机器人回复：
```
消息详细伪装，请发送伪装QQ号
剩余时间：30秒
```

2. 发送QQ号后，机器人回复：
```
消息详细伪装
<用户12345678>
请发送：文本|图片|表情
剩余时间：30秒
```

3. 发送消息内容后，机器人回复：
```
已收集1条消息
<12345678> 文本*1

请发送：QQ号|文本|图片|表情

(新QQ号可添加伪装用户，发送「结束」生成转发消息)

剩余时间：30秒
```

4. 重复步骤3，可以不断添加消息或切换伪装用户

5. 发送 `结束` 生成最终的转发聊天记录

**超时处理：**
- 30秒内未回复，机器人发送 `指令使用超时！` 并重置会话

### 3⃣ 查看帮助

**命令：** `/伪装消息帮助`

**说明：** 以转发消息形式查看完整帮助菜单

### 4⃣ 群黑名单

**命令：** `/群黑名单`

**说明：** 查看当前被拉黑的群聊列表

### 5⃣ 群白名单

**命令：** `/群白名单`

**说明：** 查看当前白名单群聊列表

### 6⃣ 黑白名单模式切换

**命令：** `/伪装群名单 <黑名单|白名单>` （别名：`伪装群设置`）

**说明：**
- `/伪装群名单 黑名单` — 切换为黑名单模式
- `/伪装群名单 白名单` — 切换为白名单模式

**模式说明：**
- **黑名单模式（默认）**：除黑名单中的群外，其他群均可使用插件
- **白名单模式**：仅白名单中的群可以使用插件

## 配置说明

插件通过 `_conf_schema.json` 定义配置项，所有配置均可在 AstrBot WebUI「插件配置」页面可视化修改，无需手动编辑文件。配置保存在 `data/config/msg_spoof_config.json`。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `blacklist_mode` | bool开关 | `开启` | 黑名单模式开关：**开启=黑名单模式**（除黑名单群外均可使用），**关闭=白名单模式**（仅白名单群可使用） |
| `blacklist` | 模板列表 | `[]` | 黑名单群号列表，点击「添加条目」可添加群号 |
| `whitelist` | 模板列表 | `[]` | 白名单群号列表，点击「添加条目」可添加群号 |

> **提示：** 也可以通过指令 `/伪装群名单 黑名单|白名单` 切换模式，通过 `/群黑名单` 和 `/群白名单` 查看列表。

## 技术说明

### 依赖
- `aiohttp` - 异步HTTP请求，用于获取QQ昵称

### 数据存储
- 插件配置通过 `_conf_schema.json` 定义，保存在 `data/config/msg_spoof_config.json`
- 支持 AstrBot WebUI 可视化配置，插件重载后数据不丢失

### 支持的消息类型
- 文本（Plain）
- 图片（Image）
- 表情（Face）

## 注意事项

1. **QQ号识别**：快捷伪装中，纯数字且5-11位的内容会被识别为QQ号。如需发送纯数字文本，请使用详细伪装模式。
2. **昵称获取**：插件通过公共API获取QQ昵称，API不可用时会直接显示QQ号本身。
3. **超时机制**：详细伪装模式30秒无操作自动重置，请及时发送消息。
4. **权限要求**：机器人需要有发送合并转发消息的权限。
5. **群管理**：黑白名单仅对群聊生效，私聊不受限制。
